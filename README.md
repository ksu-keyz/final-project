# Інтернет-магазин гвоздик `"Flora"`
**Про сайт:**
_Це сайт для замовлення гвоздик онлайн, у якому є головна сторінка з контактами, сторінка-каталог гвоздик. сторінки `"Про нас"` - про нас, де розповідається про магазин, про доставку, де розповідається про доставку та оплату та відгуки, де показано відгуки про магазин (також можна залишити свій відгук!). Якщо на сторінці `"Каталог"` натиснути на кнопку `"Детальніше"` на картці гвоздики, потрапимо на сторінку, де є вся інформація про квітку та кнопка `"У кошик"`. Ще є сторінка `"Кошик"`, де видно всі рослини, що були додані до кошика, а також можна заповнити форму для замовлення! Всі форми на сайті відправляються на пошту магазину._
**Використані технології:**
_У цьому проекті я використовувала Visual Studio Code для написання, фреймворк Bootstrap для стилів CSS, Fontawesome для іконок, Google Fonts для шрифту у футері та на сторінках `"Про нас"`, Formsubmit для надсилання форм на пошту, радники Gemini та моя мама, а також свої стилі CSS. Js писав Gemini._
